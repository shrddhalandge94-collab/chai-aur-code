# HTML Resume Assignment

This project is a simple **resume website built using pure HTML** as part of the **Chai aur Code** cohort assignments.

The objective of this assignment is to practice writing clean, semantic HTML and structuring content properly without using CSS or JavaScript.

---

## ✨ Features

- Personal details section
- Skills overview
- Work experience
- Projects section
- Education details
- Contact information

---

## 🛠 Tech Stack

- HTML5
